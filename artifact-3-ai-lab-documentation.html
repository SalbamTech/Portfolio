Artifact 03 · Hands-on exploration

AI Lab Hands-On Documentation

A structured record of learning across generative-AI platforms, organized through design thinking and developed as a reusable onboarding resource.

  • Generative AI
  • Design thinking
  • Prompt testing
  • Knowledge transfer
Course context
AIML-500 · Assignment 1.4 — AI Lab
Artifact format
Word document with screenshots and walkthroughs
Primary audience
Team members learning AI tools and project managers evaluating them
Introduction

Hands-on documentation across multiple generative-AI platforms.

Objective

Demonstrate proficiency with generative-AI tools and design-thinking application.

Process

Run shared tasks, record outputs, compare results, and document findings.

Tools & tech

ChatGPT, Claude, custom GPTs, STORM AI, and Microsoft Word.

Description

Learning a tool means testing it deliberately.

The documentation captures exploration of LLM assistants, custom GPTs, and research-focused AI systems. It records the prompts tested, representative outputs, comparative observations, quality criteria, and reflections on each platform’s strengths and limitations.

LLM assistants

Explore conversational support, drafting, reasoning assistance, and prompt sensitivity.

Custom GPTs

Examine how instructions and bounded purposes can shape a more specialized experience.

Research systems

Evaluate tools designed to organize sources, questions, and exploratory research.

Tangible artifact

The documented design-thinking cycle

  1. EmpathyUnderstand what users need from AI tools.
  2. DefinitionArticulate the problem and assess feasibility.
  3. IdeationBrainstorm AI-supported approaches.
  4. PrototypingBuild and test simple configurations or workflows.
  5. TestingValidate with real tasks and identify quality, bias, and fairness concerns.
  6. DocumentationCapture prompts, outputs, screenshots, and lessons for reuse.

Evaluation approach

Compare outputs against defined criteria.

Quality and usefulness

  • Relevance to the requested task
  • Clarity and completeness
  • Consistency across repeated trials
  • Ease of revising or verifying the result

Responsible-use considerations

  • Accuracy and unsupported claims
  • Bias and fairness concerns
  • Appropriate human review
  • Privacy and task boundaries

Process

How the documentation was created

I ran identical task prompts across several AI platforms, recorded and captured the resulting outputs, compared their quality against defined criteria, and documented the findings step by step for knowledge transfer.

Professional useThe result is designed as a reusable onboarding resource for people adopting generative-AI tools in a professional setting.

Value proposition of the artifact

Why this work matters

Unique value

This artifact demonstrates that I can learn emerging tools quickly, compare them systematically, and document processes clearly for others.

Organizational relevance

Teams implementing AI need repeatable learning resources. The documentation shows my ability to support onboarding, evaluation, and responsible adoption.
